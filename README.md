# Spotify Clone 🎵

A full-stack Spotify-inspired music streaming platform built using the MERN stack.

This project includes:
- User Authentication
- Artist Authentication
- Music Upload System
- Album Management
- Music Streaming Player
- Playlist System
- Role-Based Access
- Responsive Spotify-Inspired UI

---

# 🚀 Features

## 👤 User Features
- Register/Login
- Browse Songs
- Search Music
- Play Songs
- Create Playlists
- Like Songs
- Recently Played
- Responsive Music Player

## 🎤 Artist Features
- Artist Login
- Upload Songs
- Create Albums
- Manage Uploaded Music
- Artist Dashboard
- Edit/Delete Songs

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/spotify-clone.git
cd spotify-clone
```

---

# 🔥 Backend Setup

```bash
cd Backend
npm install
npm run dev
```

Create `.env` file inside Backend folder:

```env
PORT=5000
MONGODB_URI=your_mongodb_url
JWT_SECRET=your_secret
```

---

# 🎧 Frontend Setup

```bash
cd Frontend
npm install
npm run dev
```

Create `.env` file inside Frontend folder:

```env
VITE_API_URL=http://localhost:5000
```
